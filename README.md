# Terminal Instagram Downloader

> 一个使用 Python 构建的 Instagram 命令行下载工具
> A command-line Instagram downloader built with Python.

---

## 项目简介 | Overview

本项目用于下载 Instagram 视频和图片内容。er

支持：

* Instagram Reel 下载
* Instagram 视频帖子下载
* Instagram 图片帖子下载
* Instagram 轮播内容下载
* 批量下载
* 重复下载检测
* 下载统计与进度显示

This project supports:

* Instagram Reel download
* Instagram video post download
* Instagram photo post download
* Instagram carousel download
* Batch download
* Duplicate download detection
* Download progress tracking

---

## 功能 | Features

### 单个视频下载 | Single Video Download

```bash
ig-video
```

支持：

```text
Reel
视频帖子
视频轮播
```

Supports:

```text
Reel
Video Post
Video Carousel
```
